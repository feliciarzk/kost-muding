Muding Kerobokan Kos

A modern and responsive accommodation website developed for a family-owned boarding house in Muding, Kerobokan, Bali.

This project was created as a real-world website to help promote the property online, provide prospective tenants with essential information, and make inquiries easier through WhatsApp.

🌐 Live Website

https://room-rent-kerobokan-bali.com

📌 Project Overview

Muding Kerobokan Kos is a property promotion website designed to introduce the boarding house to potential tenants looking for accommodation in the Kerobokan, Bali area.

The website presents the property's facilities, room information, location, and other relevant details in a clean and user-friendly interface.

Instead of using a traditional booking system, the website uses WhatsApp as the main communication channel, allowing potential tenants to directly contact the property owner for availability, questions, and booking inquiries.

✨ Features

- 🏠 Property and room information
- 📸 Room and property showcase
- 🛏️ Facilities and amenities section
- 📍 Location information
- 📱 Responsive design for mobile, tablet, and desktop
- 💬 Direct WhatsApp contact for inquiries and booking
- 🔗 Custom domain
- 🔎 SEO-friendly website structure
- ⚡ Fast and lightweight frontend

🛠️ Tech Stack

- React.js — Frontend development
- Vite — Development and build tool
- Tailwind CSS — Styling and responsive UI
- JavaScript — Application logic
- Vercel — Deployment
- Domainesia — Domain registration

🎯 Project Goals

The main goals of this project were to:

1. Create a professional online presence for the boarding house.
2. Make room and facility information easy to access.
3. Improve the property's visibility through search engines.
4. Provide a simple communication flow between potential tenants and the owner.
5. Practice building and deploying a real-world website for an actual client.
